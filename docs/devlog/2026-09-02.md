## 12:35 〜 GitHub リポジトリ初期化 CLI の作成

### やったこと
- bun TypeScript 単一ファイルで `get-ready-for-github.ts` を追加した
- 引数なしはヘルプ＋カレントディレクトリの実行計画、`--init` のときだけ書き込むようにした
- `gh repo create --source` では `--license` が使えないため、LICENSE と `.gitignore` はローカルで用意する方針にした

### 詰まった点・気づき
- GitHub CLI は既存ソースからの作成時に `--license` / `--gitignore` を拒否する
- 親リポジトリ内での `git init` を止めておかないと、誤ってネストする
