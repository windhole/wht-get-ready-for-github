## 01:19 〜 CLI を --init / --doc / --dev に決めた

### やったこと
- 入力しやすさのため、Go の `flag` で扱える形にした
- `--doc` / `--dev` は `--init` なしで単体実行、に訂正した
- `--init` / `--doc` / `--dev` は 0 個または 1 個だけ（2 つ以上はエラー）
- ADR-0007 をその内容で Accepted にした

## 02:42 〜 --doc / --dev プロファイルを実装した

- README / DEVELOPING を更新した
